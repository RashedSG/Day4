# Day4 — تقديم طلب إداري

نموذج عربي (RTL) يحفظ الطلب في ملف JSON ويعرض حالته بالرقم المرجعي.

```bash
php -S 127.0.0.1:8080
```

ثم افتح: http://127.0.0.1:8080/index.html

## الملفات

- `index.html` — نموذج التقديم
- `process.php` — التحقق والحفظ
- `status.php` — الاستعلام بالرقم المرجعي
- `help.php` — المساعدة
- `inc/helpers.php` — دوال الحفظ والقراءة وXSS
- `data/requests.json` — التخزين (مجلد محمي بـ `.htaccess`)
